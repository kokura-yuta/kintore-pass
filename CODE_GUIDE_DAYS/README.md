# 筋トレPAS バックエンド15日学習

このフォルダは、長いコードガイドを毎回スクロールせず、1日分ずつ順番に学ぶための入口です。

## 使い方

1. その日のファイルだけを開く
2. 上から順番にリンク先のコードを見る
3. 「今日覚える文法」を確認する
4. 最後の理解チェックへ自分の言葉で答える
5. 一番下の「次のDayへ」を押す

毎日60〜90分を目安にします。分からない言葉があったときだけ、[全体版コードガイド](../CODE_GUIDE.md)を辞書として使ってください。
